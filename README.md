## `>` shipped

### 🏋️ [Hercule](https://gethercule.app) — fitness tracker with an AI Coach

`React Native (Expo)` · `TypeScript` · `Firebase` · `Genkit + Gemini`

On the App Store: workout logging, custom labels, calendar history. Ships an in-app AI gym companion in public beta — a server-side Gemini agent that calls typed tools to answer from your real training history, and returns a validated 7-day program as an accept-or-edit card, behind per-user token quotas and rate limiting. I ran the whole release pipeline: App Store Connect setup, metadata, ASO and store assets.

### 🔒 [A Way Out](https://awayout.app) — focus and app blocker

`Swift` · `Apple Screen Time API` · `Core NFC`

An unbypassable focus tool for iOS. Distracting apps stay locked behind a physical NFC tag, with blocking enforced at the OS level through Apple's Screen Time engine — so there is no settings menu to talk your way out of.

### ⛓️ [Gas-Optimised Batcher](https://github.com/siarkonyar/GasOptimizedBatcher) — final-year project

`Solidity` · `Blockchain`

A decentralised app that cuts the carbon footprint of crypto transactions through batching and scheduling, plus an evaluation of how transaction-grouping strategies affect gas cost and overall energy use.

### 📦 [Gümrük Beyan Tara](https://gumrukbeyantara.com) — customs declaration parser

`TypeScript` · `Python`

Splits import declarations into product items and produces a concise summary. Built to speed up my own work at IKRA Logistics — now used daily by other employees.

### 🌐 [Network Distributed System](https://github.com/siarkonyar/network-distributed-system) — local chat app

`Java` · `WebSockets`

Real-time messaging with public and private chats, plus coordinator-reassignment logic that keeps the system stable when nodes disconnect. 50+ unit tests.

### 🗓️ [Event Manager](https://github.com/siarkonyar/event-planner) — desktop scheduling system

`Java` · `JDBC` · `SQLite`

Built in a team: UML domain models, object-oriented class structures, and a repository-pattern persistence layer with full CRUD.
